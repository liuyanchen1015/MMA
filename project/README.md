# Geo-Text Alignment: Multimodal Perovskite Property Prediction

**Synergizing Crystal Graph and Generated Descriptions for Explainable Perovskite Property Prediction**

## Key Idea

We combine **CGCNN** (crystal graph neural network) with **SciBERT** (scientific text encoder) to predict band gap of ABO3 perovskite oxides. Text descriptions are machine-generated by [Robocrystallographer](https://github.com/hackingmaterials/robocrys), requiring zero human annotation.

## Results Summary

| Model | Modality | MAE (eV) | R² |
|-------|----------|----------|-----|
| CGCNN | Structure | 0.656 | 0.620 |
| SciBERT (frozen) | Text | 1.215 | 0.187 |
| SciBERT (finetune) | Text | 0.751 | 0.554 |
| Concat Fusion | Struct + Text | 0.583 | 0.639 |
| Gated Fusion | Struct + Text | 0.550 | 0.664 |
| **FiLM Fusion** | **Struct + Text** | **0.509** | **0.674** |
| Aligned + FiLM | Struct + Text | 0.588 | 0.658 |

Best model (FiLM Fusion) reduces MAE by 22% over structure-only baseline.

## Dataset

- **Source**: Materials Project API
- **Scope**: 592 ABO3 perovskite oxides (493 with text)
- **Modalities**: Crystal structure (CIF) + Robocrystallographer text
- **Targets**: Band gap (eV), Formation energy (eV/atom)
- **Split**: 80/10/10 (train/val/test)

## Key Findings

1. **Multimodal fusion consistently outperforms single-modality baselines.** FiLM Fusion achieves 22% MAE improvement.
2. **Fusion strategy matters.** FiLM > Gated > Concat — asymmetric modulation works best.
3. **Machine-generated text carries real signal.** SciBERT-finetune alone reaches R²=0.55.
4. **Contrastive alignment works but doesn't beat end-to-end fusion on small data.**
